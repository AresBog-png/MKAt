# MKAt: личные чаты, группы, каналы, фото. Бесплатный сервер и настоящий APK

Всё бесплатно: сервер Supabase, сборка APK на GitHub, хостинг веб-версии на Cloudflare Pages (по желанию).

## 1. Сервер (Supabase)
1. supabase.com → New project.
2. Authentication → Sign In / Providers → включите **Allow anonymous sign-ins**.
3. SQL Editor → New query → вставьте весь `schema.sql` → Run.
   (Он удалит таблицы старой версии MKAt, если вы их создавали.)
4. Project Settings → API: скопируйте **Project URL** и ключ **anon public**.
5. В `www/index.html` найдите `var CFG={url:"",key:""};` и вставьте их.

## 2. Сборка APK (GitHub, без Android Studio)
1. github.com → New repository (`mkat`).
2. Загрузите всё содержимое папки (www, package.json, capacitor.config.json, .gitignore, папку .github). Если `.github` не загрузилась: Add file → Create new file → имя `.github/workflows/build-apk.yml` и вставьте содержимое одноимённого файла.
3. Actions → «Build MKAt APK» → Run workflow (5–8 минут).
4. Скачайте из раздела Artifacts файл **MKAt-apk**, внутри `app-debug.apk`. Отправьте на телефон и установите (разрешите установку из этого источника).

Папку `www` можно также загрузить на Cloudflare Pages: получится веб-версия, которая ставится как PWA.

## Что умеет приложение
- **Личные чаты**: ✎ → «Личное сообщение» → введите @username собеседника.
- **Группы**: любой участник пишет; владелец и админы добавляют людей по @username; группу можно сделать публичной.
- **Каналы**: пишут только владелец и админы, остальные читают. Публичные каналы находятся через «Найти группы и каналы».
- **Фото**: кнопка 📎 (сжимается до 1280 px, хранится в Supabase Storage).
- **Уведомления о новых сообщениях**, пока приложение запущено или свёрнуто.
- Удаление своих сообщений (в группах и каналах админы удаляют любые), выход из чата, список участников (нажмите на шапку чата).

## Ограничения (честно)
- Уведомления работают, пока приложение открыто или недавно свёрнуто. Когда Android полностью закрывает приложение, уведомления не приходят: для этого нужен Firebase Cloud Messaging и серверная функция. Это отдельный шаг.
- Вход анонимный: аккаунт привязан к устройству. Если очистить данные приложения или сменить телефон, аккаунт потеряется. Для постоянных аккаунтов нужно добавить вход по почте или телефону.
- Фото лежат в публичном хранилище под случайными адресами: увидеть фото может только тот, у кого есть ссылка, но это не сквозное шифрование. Тексты тоже не зашифрованы сквозным шифрованием.
- Нет голосовых и видеозвонков, файлов кроме фото, ответов на сообщения, реакций.
- Бесплатный тариф Supabase ограничен по базе, хранилищу и трафику, а проект без активности около недели ставится на паузу. Актуальные цифры смотрите на supabase.com/pricing.
